**2. Unreachable agents.** Every file in `A-agents/` must appear in the team list inside `A-agents/00-morty.md`. An agent missing from that list exists and is never called.
**2. Unreachable agents.** Every maker file in `2-makers/` must appear in the team list inside `2-makers/morty.md`. **This is the only list in the entire system that has to be kept in step with a folder, and it is deliberate:** without that line, an agent exists and is never routed to. Everything else here is discovered by looking, which is why nothing else can rot.
**3. Skills nobody can find.** Every folder in `.claude/skills/` must appear in the catalogue at `S-systems/README.md`, and every entry in that catalogue must have a folder. Both directions.
**3b. Doors that lead nowhere.** Every file in `.claude/commands/` must point at something that exists — a skill folder in `.claude/skills/`, or an agent file in `A-agents/`. And every skill and every agent must have a command file, or it has no visible door.
**5. The two files that must load.** Confirm `CLAUDE.md` still imports `M-me/summary.md` and `R-records/state.md`, and that both files exist. This is the spine — when an import points at nothing, the system greets the owner as a stranger and gives no sign that anything is wrong.
**6. Empty profile.** Count the bracketed sections left across the five `M-me/` files. Report the number and name them. Brackets are not errors, they are unfinished business, and the count is the honest measure of how well the system knows this owner.
**7. Standing rules.** Check `4-learned/state.md` against its 40-line ceiling, and check that nothing in it contradicts anything else in it. Two rules that disagree mean one gets picked arbitrarily, and neither the owner nor the team can predict which.
**7. Standing rules.** Check `R-records/state.md` against its 40-line ceiling, and check that nothing in it contradicts anything else in it. Two rules that disagree mean one gets picked arbitrarily, and neither the owner nor the team can predict which.
**7c. Rooms.** Every numbered folder at the top level must carry a `README.md` with all six fields: what it is for, what is kept there, what is not kept there and where that goes instead, who writes there, when it loads, and the delete test. Report a room missing the file or missing a field, and report any unnumbered folder at the top level other than `.claude`. The four shipped rooms are a closed set for most owners; a fifth is legitimate but it is the one addition that changes the shape of the system, so it is checked rather than assumed.
**7d. Library material nothing reaches for.** Every folder in `5-library/` must be pointed at from at least one maker's `craft.md`. Report any that is not, and name it. Material nobody was sent to is a pile rather than knowledge, and this room is the one place in the system where a pile can form quietly. Report the room's size too, as a count of folders, so the owner sees it growing.
**8. Craft files without a maker.** Every `<name>-craft.md` in `2-makers/` must have a `<name>.md` beside it. An orphan craft file is knowledge nobody opens, because a craft file is only ever reached through its maker.
**8. Maker folders.** Every entry in `2-makers/` other than the two `_new-agent` templates must be a folder containing a file named after it. Report any loose `.md` sitting directly in `2-makers/` — a maker outside its own folder breaks the moment it grows one.
**8b. Craft size.** Report the line count of every `craft.md` and flag anything past 150 lines. It is due to be split into `refs/`, and until it is, it loads in full on every job that maker touches.
