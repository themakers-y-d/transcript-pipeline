# צינור תמלולים, בבעלות מלאה שלך

כל פגישה שאתה מקליט ב-Wispr Flow עולה כל לילה לתיקייה משותפת ב-Google Drive, ובבוקר נספגת לתוך הזיכרון של הסוכנים שלך: מי היה בחדר, מה נסגר לעומת מה רק נאמר, ומה כל סוכן צריך ללמוד מזה. הצוות שלך מתעדכן לבד מהפגישות שלך, בלי שתעתיק שום דבר ביד. הכל רץ על החשבונות שלך, המידע נשאר אצלך, ואין מנוי.

## איך מתקינים

לא קוראים כלום ולא מתקינים ביד. פותחים את קלוד קוד בתיקייה כלשהי, ומדביקים לו את זה:

```
שכפל את הריפו הזה ולך לפי הקובץ INSTALL.md שבתוכו, שלב אחרי שלב:
https://github.com/themakers-y-d/transcript-pipeline
לפני כל שלב תסביר לי במשפט מה עומד לקרות ומה צריך ממני, ואם צריך שאלחץ משהו בעצמי, עצור ותגיד לי.
```

קלוד עושה את רוב העבודה לבד. ממך יידרשו כמה אישורים חד-פעמיים בדפדפן: לחבר את Wispr Flow ואת Google Drive, ולאשר ל-macOS להציג התראות. משם והלאה הצינור רץ לבד כל לילה, ואין מה לתחזק.

## מה מיוחד כאן

זה לא סקריפט שקלוד ממציא מחדש בכל התקנה. אלה הסקריפטים המדויקים שרצים כל לילה אצל מי שבנה את הערכה מאז אוגוסט 2026, מנוקים מכל פרט אישי. כל מלכודת שנפלנו בה כבר פתורה בפנים: החיבור שמת בשקט ולא רואים, הפגישה הארוכה מדי שנכשלת בלי שאף אחד שם לב, קובץ המעקב שאם יתאפס יעלה הכל פעמיים, והג'וב הלילי שמפסיק להתחיל ואין מי שיצעק.

## מה יש בתיקייה

`INSTALL.md` הוא ההוראות שקלוד מבצע. `scripts/` הם שני הסקריפטים, המעלה והסופג, עם קובץ הגדרות אחד למלא. `launchd/` הן תבניות התזמון. `transcript-protocol.md` הוא הפרוטוקול שהסופג מריץ על כל תמלול, כולל שערי הבטיחות שמונעים ספיגה של רעש רקע או של מספר שגוי.
